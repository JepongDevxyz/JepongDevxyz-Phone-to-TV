# Send Files to TV — Jepong Devxyz

Native Android local file-transfer app for phones, Google TV and Android TV.

## Targets
- Phone → TV, TV → Phone, Phone → Phone, TV → TV
- Send and Receive on every device
- Same-Wi-Fi discovery with Android NSD
- 6-digit pairing and QR payload support
- Multiple files, progress, cancel, retry and resumable transfer protocol
- Photos, videos, music, documents, ZIP and APK
- Android 6.0 (API 23) through Android 16 (API 36)
- Touch, D-pad and large-screen responsive UI

GitHub Actions builds the debug APK and source ZIP. Release verification is based on CI artifacts.
